About Project & Academic Details

2nd-Year B.Tech Computer Science / IT Educational Project Documentation

Academic Project

1. Problem Statement & Objectives

Foundations

Core Problem

Many first-time credit seekers and students do not understand how income, repayment behavior, and existing debt obligations interact to determine creditworthiness. Most commercial scoring systems (such as CIBIL or FICO) operate as proprietary, opaque black boxes, making it difficult for learners to understand cause-and-effect relationships when managing their personal finances.

Project Objective

The objective of this project is to build a transparent, rule-based Credit Score Simulation Engine that estimates creditworthiness on a clean 0–100 scale, explains every mathematical calculation step-by-step, and allows users to simulate hypothetical financial decisions to observe how their score dynamically changes.

2. Proposed Solution & Key Features

System Architecture

Deterministic Rule Engine

Uses clearly defined bracket intervals and ratio formulas without hidden variables. Every point in the final score is mathematically traceable.

Financial Decision Simulator

Allows side-by-side comparison of a current baseline profile with a simulated hypothetical state (e.g. taking a ₹2.5L loan or missing 3 payments).

Explainable Viva Breakdown

Generates step-by-step algebraic breakdowns (e.g. 80×30% + 90×50% + 70×20% = 83) suitable for mentor evaluation.

3. Scoring Methodology & Software Architecture

Software Design

The software architecture decouples the scoring computation logic from the UI view layer. The calculation flow follows the Strategy Pattern:

User Input
    ↓
Income Scoring Strategy     [Range mapping: <20k→40, 20k-40k→60, 40k-60k→80, ≥60k→100]
    ↓
Repayment Scoring Strategy  [(On-time / Total) × 100]
    ↓
Debt Scoring Strategy       [0-50k→100, 50k-100k→70, 100k-200k→50, >200k→30]
    ↓
Weight Application          [Income × 0.30 + Repayment × 0.50 + Debt × 0.20]
    ↓
Final Score (0–100) & Rating Classification (GOOD / AVERAGE / POOR)
    ↓
Simulation Engine & Delta Analysis

5. Project Limitations

Academic Scope
Academic Disclaimer: This project uses predefined educational rules and does not represent an actual credit bureau scoring methodology.
  • Limited Factor Set: Evaluates three primary factors (income, repayment, debt) rather than the multi-dimensional vectors used in industrial engines.
  • Predefined Thresholds: Uses discrete range brackets rather than continuous statistical score distributions.
  • No Real Bureau / Banking Data: Uses client-side demo and simulated parameters exclusively.
  • No Credit Decisions: Does not approve loans, extend credit lines, or offer financial advisory services.

7. Viva Demonstration & Mentor Q&A Guide

Viva Prep
Q1: How does the system compute the standard demo score of 83?

For Income = ₹50,000 (score = 80 × 0.30 = 24), Repayment = 9/10 = 90% (score = 90 × 0.50 = 45), and Debt = ₹1,00,000 (score = 70 × 0.20 = 14). Total score = 24 + 45 + 14 = 83 (Rating: GOOD).

Q2: What happens in the simulation when debt increases to ₹2,50,000?

The debt score falls from 70 (bracket ₹50k–₹1L) to 30 (bracket >₹2L). Weighted debt contribution drops from 14 to 6 (-8 pts). Final score changes from 83 to 75 (Rating changes to AVERAGE).

Q3: Why is the Strategy Pattern appropriate for this design?

It encapsulates the scoring algorithm for each individual factor independently. If the university mentor requests changing the income bracket or adding a fourth factor, only that specific scoring strategy is edited without altering the final score aggregator.
